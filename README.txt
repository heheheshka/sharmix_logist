Особо ценный груз — v7
Откройте index.html через локальный сервер (например, VS Code Live Server). На компьютере используйте стрелки; на телефоне можно управлять пальцем или кнопками.

Изменения v7: грузовик крупнее, направления написаны полностью, зеленый — сервис, синий — экспертиза; улучшенная логика появления шармиксов и разнообразия мест падения. Добавлены короткие ретро-звуки и демонстрационная фоновая музыка с кнопкой ♪.

Файлы двух пользовательских шрифтов НЕ входят в архив. Для окончательной типографики положите свои Classic-Console-Neue-Regular.ttf и LabGrotesque-Medium.ttf в папку fonts.

Ссылка на программу шармиксов задается через SHARMIX_URL в начале game.js.


V8: Музыка Flowerbed Fields включается по кнопке ♪ с громкостью 5.5%; сначала выключена. Для офлайн-версии см. AUDIO_README.txt. Индикатор экспертизы теперь голубой (#7BD5FF).

Версия 9: музыка звучит немного громче (10% вместо 5.5%).
На стартовом экране появилась кнопка «Музыка: выкл./вкл.». Ее состояние синхронизировано с кнопкой ♪ в игре.
